There's a Minecraft server for people in the fellowship to build and hang out together.

## Join

1. Open **Minecraft Server** from the sidebar's extras.
2. Follow **Getting started** for the server address and the version to use.
3. The **plugin FAQ** explains the server's extra features.

Be kind, and keep it the kind of place you'd want a newcomer to find.
