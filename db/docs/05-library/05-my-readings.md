**My readings** (in the sidebar) is where you write readings for meetings you host: a passage, a topic, a few questions.

## Write one

1. Open **My readings** and choose **New reading**.
2. Give it a title and source, and write or paste the text.
3. Add **tags** so others can find it.
4. Save it. It stays yours until you publish.

## Publish

Choose **Publish** to add it to the [Reading Archive](/docs/meetings/reading-archive) for everyone. You can unpublish it later.

## Add a poll

Choose **Add a poll** to ask the room a question right under the reading. See [Polls](/docs/meetings/polls).
