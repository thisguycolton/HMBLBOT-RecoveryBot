**My readings** (in the sidebar) is where you write readings for meetings you host: a passage, a topic, a few questions.

![My readings](/docs-images/library/my-readings.webp)

## Write one

1. Open **My readings** and choose **New Reading**.
2. Give it a title and source, and write or paste the text.
3. Add **tags** so others can find it.
4. Save it. It stays yours (a **Draft**) until you publish.

Tabs at the top filter **All**, **Published**, **Scheduled** and **Drafts**; each card has **Preview** or **View**, **Edit** and delete.

## Example

Sam has two readings:

- **Showing up anyway** (Draft): "Some mornings the last thing I want is a 6:30 meeting. I go anyway, and I've never once regretted it." Sam will read it at the Sunrise Big Book Study next week.
- **Gratitude in a hard week** (Published, tagged `gratitude`): it's in the [Reading Archive](/docs/meetings/reading-archive) for anyone to find.

## Publish

Choose **Publish** to add it to the [Reading Archive](/docs/meetings/reading-archive) for everyone, now or at a time you pick (**Scheduled**). You can unpublish it later.

## Add a poll

Choose **Add a poll** to ask the room a question right under the reading. See [Polls](/docs/meetings/polls).
