## Hashtags

Type **#** in a note (on your timeline or on a highlight) to add a tag like `#gratitude` or `#step3`. As you type, tags already in use are suggested with how often they're used.

Choose a tag anywhere to see every note with it that you're allowed to see. Tags also show in the top search box.

## Mentions

Type **@** and a name to mention someone. They get a notification. In group chat you can also mention roles and service positions; see [Group chat](/docs/group-tools/group-chat).

> [!PRIVACY] Tag pages only show notes you could already see. A private note's tags never show to anyone else.
