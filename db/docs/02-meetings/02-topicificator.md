The **Topicificator 9002** picks a topic for a discussion meeting: a question or a theme with a short reading to get people talking.

## Draw a topic

1. Open **Topicificator** from the sidebar.
2. Choose a **topic set** (or All topics) and, if you like, a category.
3. Press **Draw**. Don't like it? Draw again.
4. Read the topic aloud, or share your screen so everyone can read along.

## The timer

Set a share time (for example 3 minutes) and start the timer for each person. It's big and easy to read on a shared screen, with a gentle warning before time is up.

## Running it from a HostDeck

When your group hosts from a [HostDeck](/docs/group-tools/hostdeck), the host can open a **live Topicificator** window. Share that window in Zoom: the host draws topics and runs the timer from the deck, and the shared window follows along.

> [!TIP] Topics are curated by the RecoveryBot team. Have a good one to suggest? [Send it to us](/contact).
