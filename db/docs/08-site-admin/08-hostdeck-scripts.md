**Site Admin > HostDeck scripts** lists the meeting scripts host coordinators can pick under **Set up HostDeck > Script > Start from a template**. The built-in **Online meeting host format** is modeled on a real group's host format, with group-specific details turned into parts in parentheses.

## Edit a script

1. Choose a script. It opens in the same document editor groups write their formats in.
2. Use **Insert > Add Section** for each step the hosts go through, **Milestone Form** for celebrations, and **Dynamic Values** for things that fill themselves in, like `{{ meeting }}` or `{{ service_hiw }}`.
3. **Save**. Groups that copy it from now on get the new text; groups that already copied it keep their own copy.

**Put back as it came** returns the built-in script to its original text.

## Add, rename and remove scripts

- **New script** starts a blank one; the copy button beside a script starts from that one. You can also import a Word, Markdown or RecoveryBot JSON file.
- Change the **Name** and **What it's for** at the top of the editor.
- **Offer to groups** shows or hides a script from host coordinators. New scripts start hidden.
- The arrows change the order groups see them in.
- **Delete** removes a script you added. The built-in one can be hidden but not deleted.
