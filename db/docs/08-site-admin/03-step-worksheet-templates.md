**Site Admin > Step worksheets** lists the worksheets members can start on the Steps page.

## Edit a worksheet

1. Choose a worksheet. It opens in the HumbleBot Editor, in template mode.
2. Make your changes. **Save** keeps a draft only admins see.
3. **Publish** makes the draft the next version. New worksheets start from it; work members already started keeps its own copy.

**History** lists the versions; **Go back** makes a draft from an earlier one.

## Other settings

- **Default**: the worksheet a step offers first.
- **Hide**: take a published worksheet off the Steps page.
- **New worksheet** starts a blank one, or import a JSON or YAML file.

Lists show how many people started each worksheet, never what anyone wrote.
