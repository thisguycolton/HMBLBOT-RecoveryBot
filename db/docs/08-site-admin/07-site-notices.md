**Site Admin > Site notices** puts a banner at the top of the site.

![Site Admin > Site notices, with one notice scheduled](/docs-images/site-admin/notices.webp)

1. Choose **New notice**.
2. Write a short headline, and a longer write-up if you need one (it opens in a window).
3. Pick a tone (news, info, warning) and when it starts and ends.
4. Save. It shows to everyone until it ends or they close it.

## Example

To announce a new feature, Sam writes the headline "New: share a chip as a picture", the summary "Open any chip and choose Picture or video to post it anywhere.", picks the **info** tone, links it to the Chips docs page with the label "How it works", and sets it to start in three weeks. Until then the list shows it as **Starts Nov 28**; **Turn off** stops it early.
